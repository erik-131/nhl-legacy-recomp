# Feature proposals

Every feature proposal comes here first: assess what is possible, then record the outcome, then add it to
[roadmap.md](roadmap.md) if it is to be done. An assessment says what it rests on: **measured**, **read** (code or data
read, not run), **estimate** or **not investigated**. 

Status: **assess** (not assessed yet), **planned** (in the roadmap), **in progress**, **done**, **not planned** (reason
given), **the maintainer decides**.
